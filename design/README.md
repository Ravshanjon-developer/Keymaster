# Design artifacts

This folder is **not application code**. It does not change the KeyMaster web app.

`keymaster-product-map-figma/` is a Figma Desktop plugin that recreates the **current** UI as a product map (stage 1: no redesign).

See `keymaster-product-map-figma/README.md` to import it and generate the file **KeyMaster — Product Map (Current UI)**.
